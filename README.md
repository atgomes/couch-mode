# Couch Mode

Turn a Windows PC into a home console: boot to a controller-friendly launcher, stream to a phone or Steam Deck, wake it from the TV.

Live site: https://atgomes.github.io/couch-mode/ (once published)

Built with [Astro Starlight](https://starlight.astro.build) and deployed to GitHub Pages by `.github/workflows/deploy.yml`.

## Develop

```bash
npm install
npm run dev     # http://localhost:4321/couch-mode/
npm run build   # output in dist/
```
